# Sum up 23 November's world news in one image

One-page newspaper digest of Monday 23 November 2026: 15 dated stories grouped by region, each with a flag, pictogram and short headline, plus a world map with red dots marking story locations. The plush make.fun ghost reads the day's paper in the masthead.

`main.py` copies the bundled `entry.png` to `/output/entry.png`.
